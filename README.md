# 로또 게임

자바(Java 21)와 Gradle 을 이용해 구현한 콘솔 기반 로또 게임 애플리케이션입니다.
우아한테크코스 프리코스 3주차 미션으로, 객체 지향 설계를 고민하며 개발했습니다.

## 주요 기능

- 로또 구입 금액 입력
- 구입 금액에 따른 로또 자동 발급 및 번호 출력
- 당첨 번호 및 보너스 번호 입력
- 당첨 통계 및 총 수익률 계산
- 예외 발생 시 에러 메시지 출력 후 재입력 처리

## 기술 스택

- Java 21
- Gradle
- JUnit 5
- AssertJ

---

## 📋 구현 기능 목록

#### 입력 기능

- 로또를 구입할 금액을 입력한다.
- 로또 당첨번호를 입력한다.
- 보너스 번호를 입력한다.

#### 입력 검증 기능

- 입력 값이 빈 값이거나 Null 이면 예외가 발생한다.
- 로또 번호와 당첨번호가 6개가 아니면 예외가 발생한다.
- 로또 번호와 당첨번호에 중복된 번호가 있다면 예외가 발생한다.
- 보너스 번호가 당첨 번호와 중복되면 예외가 발생한다.
- 당첨 번호가 1~45 범위 내의 숫자인지 검증한다.
- 구입 금액이 숫자가 아닌 문자가 입력되었는지 검증한다.
- 구입 금액이 양수인지 검증한다.
- 구입 금액이 1,000원 단위인지 검증한다.

#### 로또 생성 기능

- 6개의 정렬된 번호를 가지는 로또 하나를 생성할 수 있다.
- 금액에 맞는 로또를 여러 개 생성할 수 있다.

#### 당첨 확인 기능

- 당첨 번호와 로또 번호를 비교하여 일치하는 갯수를 반환할 수 있다.

#### 통계 계산 기능

- 총 결과를 저장할 수 있다.
- 수익률을 계산할 수 있다.

#### 출력 기능

- 에러 메시지를 출력한다.
- 결과를 출력한다.

#### 예외 처리 기능

- 예외가 발생하면 사용자 입력을 재시도 할 수 있다.

## 클래스 구조

- **LottoController** : 전체 흐름과 입력 및 출력을 관리하는 클래스
- **InputView** : 사용자의 입력을 받는 클래스
- **OutputView** : 사용자 안내 및 결과를 출력하는 클래스
- **InputValidator** : 사용자의 입력 값을 검증하는 클래스
- **Lotto** : 로또 도메인 객체
- **WinningLotto** : 당첨 로또와 보너스번호를 가지는 클래스
- **LottoGenerator** : Lotto 를 생성하는 클래스
- **LottoResultCalculator** : 수익률을 계산하고 당첨결과를 저장하는 클래스
